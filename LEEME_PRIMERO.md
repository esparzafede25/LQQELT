# Carpeta principal del juego

Desde el 4 de octubre de 2026, abrir en Antigravity esta carpeta completa:

`H:\TP FINAL I.C\Lo que queda en la Tierra -  JUEGO`

Incluye el código, todas las imágenes y videos, referencias, documentos de continuidad y pruebas. No necesita conectarse a Runway para reproducir las animaciones. La carpeta `juego-pulido` de Codex queda como respaldo de la copia de esta fecha; no editar ambas en paralelo.

Para trabajar, abrir esta carpeta en Antigravity y ejecutar `npm run dev`. Para probar el juego, abrir la dirección que muestra el servidor (por defecto `http://localhost:3017/`). El archivo index.html debe servirse desde ese servidor, no abrirse con doble clic.

Durante la verificación de esta copia se usa `http://localhost:3018/` para distinguirla del respaldo. El progreso del navegador puede variar entre puertos; los archivos del juego no se pierden por ese cambio.

Mate, Taller y Radio tienen nuevas versiones integradas. El presente y el cierre todavía requieren la siguiente pasada. Leer `CONTINUAR_EN_ANTIGRAVITY.md` y `ENTREGA_26_OCTUBRE.md` antes de continuar.
